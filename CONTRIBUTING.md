# Cómo contribuir

## Flujo de trabajo
1. Crear una rama desde `main` con prefijo: `feat/`, `docs/`, `fix/` o `chore/`.
2. Hacer commits pequeños con mensajes claros (`docs: ...`, `feat: ...`).
3. Abrir un pull request usando la plantilla del repositorio.
4. Otro integrante revisa: contenido jurídico (Kristel, Juan Carlos) o técnico (Herbert).
5. Se fusiona a `main` solo con la revisión aprobada.

## Reglas del proyecto
- Cada dato debe citar fuente oficial, enlace y fecha.
- Herbie MCP no emite recomendaciones ni dictámenes.
- Nunca subir credenciales, llaves de API ni datos personales.
- El código del servidor vive en un repositorio privado; aquí solo documentación, Skills & Rules y evidencia.
